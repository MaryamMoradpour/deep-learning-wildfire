# Deep Learning for Wildfire Ground Heat Flux Prediction

## Overview

This repository presents a deep learning framework for predicting wildfire ground heat flux using atmospheric variables generated by WRF-SFIRE simulations. The project investigates whether convolutional neural networks (CNNs) can accurately approximate computationally expensive wildfire simulations while preserving the underlying physical relationships.

The work was developed as part of my postdoctoral research at the Karlsruhe Institute of Technology (KIT).

---

## Motivation

Wildfire behavior depends on complex interactions between atmospheric conditions, vegetation, terrain, and combustion processes. High-fidelity numerical models such as WRF-SFIRE provide detailed simulations but require substantial computational resources.

This project explores deep learning as a surrogate modeling approach to accelerate predictions of ground heat flux. The objective is to maintain high predictive accuracy while significantly reducing computational cost, supporting faster wildfire analysis and future forecasting applications.

---

## Main Features

- Deep learning model implemented in PyTorch
- Processing of WRF-SFIRE NetCDF simulation outputs
- Multi-channel atmospheric input data
- Ground heat flux prediction
- Training and evaluation pipeline
- Visualization of prediction performance
- Scientific reproducibility and modular code structure

## Workflow

1. Read WRF-SFIRE NetCDF files
2. Extract atmospheric variables
3. Normalize data
4. Train CNN model
5. Predict ground heat flux
6. Evaluate performance
7. Visualize results

---

## Dataset

The original WRF-SFIRE simulation dataset is not distributed through this repository because of its large size and usage restrictions.

Input variables include atmospheric state variables such as:

- Temperature
- Water vapor mixing ratio
- Wind components
- Vertical velocity

Target variable:

- Ground heat flux (GRNHFX)
