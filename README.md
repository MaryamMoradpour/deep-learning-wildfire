# Deep Learning for Wildfire Spread and Intensity Prediction

**Official PyTorch implementation accompanying the paper**

**Convolutional Neural Networks for Wildfire Spread and Intensity Prediction**

---

## Overview

Wildfire simulations provide essential information for understanding fire behavior and supporting emergency response. However, high-fidelity physics-based models such as **WRF-SFIRE** require significant computational resources, making large-scale or real-time applications challenging.

This project presents a **Convolutional Neural Network (CNN)** surrogate model that predicts **ground heat flux (GHF)** directly from atmospheric and fuel-related variables generated by WRF-SFIRE simulations. The proposed model significantly accelerates prediction while maintaining strong agreement with the original numerical simulations.

This work was developed during my postdoctoral research at the **Karlsruhe Institute of Technology (KIT)**.

## Dataset

The model is trained using wildfire simulations generated with **WRF-SFIRE**.

The original dataset is **not included** in this repository because of its size.

### Input Variables

* Air temperature
* Wind components (U, V, W)
* Water vapor mixing ratio
* Fuel characteristics
* Atmospheric stability information

### Target Variable

* Ground Heat Flux (GRNHFX)

---

## Model

The proposed CNN employs a **multi-scale convolutional architecture** that extracts both local and large-scale wildfire patterns using multiple kernel sizes.

The network is designed to efficiently learn the nonlinear relationship between atmospheric variables and wildfire heat release.

---

## Results

The proposed model achieved strong predictive performance on unseen wildfire simulations.

| Metric |      Value |
| ------ | ---------: |
| RMSE   | 14.3 kW/m² |
| MAE    |  6.6 kW/m² |
| R²     |       0.84 |

The repository also includes:

* Prediction contour maps
* Error maps
* Density scatter plots
* SAL analysis
* Training curves
